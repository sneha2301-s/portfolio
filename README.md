# Sneha S | Portfolio

Personal portfolio of Sneha S, Full-Stack Web Developer (Python, Flask, FastAPI, MySQL).

Plain HTML, CSS and JavaScript. No build step. Dark mode by default, light mode via the toggle.

## Files
- `index.html` the portfolio (profile photo is embedded in this file)
- `assets/profile.jpg` profile photo (copy)
- `assets/Sneha_S_Resume.pdf` resume download

## Deploy on GitHub Pages
Settings > Pages > Deploy from a branch > main > / (root) > Save.
